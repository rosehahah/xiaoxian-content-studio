# 海外原生改写

国内成品不是发布到海外的自动指令。只有用户选择了海外目的地，才准备该渠道的版本。共用原始事实与证据，分别确定目标读者、具体问题、应兑现的收益、论点和组织方式；中文正文是来源之一，不是固定英语结构。

## 重新写作的检查

- 从原始材料抽取可引用的事实、作者声音、数字范围与失败条件，再看中文成品如何使用了它们。
- 问这个目的地的读者为何要读、需要什么背景、能执行什么。补充必要的文化/专业解释，删去无关背景，不补虚构海外用户、反馈或成绩。
- 重新选择标题、开头与证据顺序，独立写英语。翻译可以帮助理解材料，不能用逐段替词作为最终适配。
- 做英语自然化编辑，保留原作者已有观点和声音。英文 Humanizer 只有实际入口可读时才记为使用；否则如实标注参考规则/Agent 编辑，不暗示已安装。
- 把成稿逐条对回事实记录，检查建议与亲历、估计与测量、功能与效果是否被强化。图片里的英语确定后重新排版，图卡不只替换中文文字。

## 首批渠道的编辑起点

这些是编辑建议，不是官方算法规律。

**Substack**：面向愿意持续理解作者实践的订阅读者，用具体事件、判断、证据、过程和取舍展开。经验文给读者可复制资源，日志保留真实选择与未完成状态。文章、邮件发送和原生草稿是不同动作；AI透明度说明按实际规则保留，不以检测工具作为作者身份判断。

**LinkedIn短帖/图片/PDF**：选出一个专业价值，用简短背景和可执行发现证明，结尾只提出与本篇有关的讨论或行动。原生 Articles/newsletter 是独立格式，Posts API 的外部文章链接卡片不能当作原生正文发布能力。未核实的接口不以网站自动化绕过。

**X/Threads短帖与图卡**：一条内容给一个具体发现或成果，多图按读者理解顺序展开。可引用完整文章，但短帖本身也应有价值，不把全部版本机械截成同样的摘要。平台图片、文字附件、Articles、媒体容器与草稿能力按当前适配器分别确认。

交付按 `channel + format + locale` 保留独立文本、图片说明与版本。中文改动影响哪些海外事实需明确核对；只改某个平台开头，不自动覆盖其他版本。所有成品仍由用户确认后进入已授权的交付步骤。
